# Ảnh poster theo dữ liệu mẫu của nhóm

Dữ liệu mẫu (file `CinemaBooking.bak`) đặt `PosterUrl` của phim theo dạng `/images/movies/<tên-file>.jpg`.
Đặt ảnh (có quyền sử dụng) vào thư mục này với đúng các tên sau để poster hiển thị:

| Phim | Tên file |
|---|---|
| Bộ Tứ Báo Thủ | `bo_tu_bao_thu.jpg` |
| Nhà Bà Nữ | `nha_ba_nu.jpg` |
| Cua Lại Vợ Bầu | `cua_lai_vo_bau.jpg` |
| Tử Chiến Trên Không | `tu_chien_tren_khong.jpg` |
| Lật Mặt 7: Một Điều Ước | `lat_mat_7.jpg` |
| Hai Phượng | `hai_phuong.jpg` |
| Mai | `mai.jpg` |
| Mắt Biếc | `mat_biec.jpg` |
| Ngày Xưa Có Một Chuyện Tình | `ngay_xua_co_mot_chuyen_tinh.jpg` |

Phim mới thêm qua trang Quản trị có thể dùng thư mục `/images/posters/` (xem README ở đó).
Nếu chưa có ảnh hoặc ảnh lỗi, giao diện tự hiển thị `/images/no-poster.svg`.
